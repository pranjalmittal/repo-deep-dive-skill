# Changelog

All notable changes to this project are documented here. This project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-30

### Added

- Portable `SKILL.md` workflow for producing a `REPO_GUIDE.md` with verified
  `path:line` citations.
- `scripts/repo_survey.py` for read-only structural surveys.
- `scripts/check_paths.py` for verifying cited paths and line numbers.
- `install.sh` with agent presets, project/personal scope, `--link`, and `--ref`
  for pinned installs.
- Representative eval cases under `evals/` and graded benchmark outputs under
  `benchmarks/`.
